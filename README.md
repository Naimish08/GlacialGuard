# 🌊 Glacier Lake Outburst Flood (GLOF) Prediction Resources  

This repository compiles useful datasets, satellite imagery sources, and research materials for studying **Glacial Lake Outburst Floods (GLOFs)** and developing predictive models using remote sensing and machine learning.  

---

## 📡 Satellite Imagery & Datasets  
- 📊 **[Glacial Lake Dataset – Kaggle](https://www.kaggle.com/datasets/aatishshresthaa/glacial-lake-dataset)**  
  A collection of satellite image snippets of glacial lakes across Nepal, China, and Pakistan in the Himalayan region.  

- 🛰️ **[ESA Sentinel – Near Real-Time Data](https://sentinel.esa.int/web/sentinel/home)**  
  Provides live updates of satellite data for continuous glacier and lake monitoring.  

- 🌍 **[NASA LANCE (Land, Atmosphere Near real-time Capability for EOS)](https://earthdata.nasa.gov/earth-observation-data/near-real-time)**  
  Access to near real-time Earth observation data streams, including glacier monitoring.
