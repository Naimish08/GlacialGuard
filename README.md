# Glacier Lake Outburst Flood Prediction Resources

## Satellite Imagery Data Sources
- **[NASA Earthdata (Landsat, MODIS)](https://www.earthdata.nasa.gov)**  
  Comprehensive satellite imagery datasets for Earth observation including glacier and lake monitoring.  

- **[ESA Sentinel Hub](https://developers.google.com/earth-engine/datasets)**  
  Access to high-resolution Sentinel-1 and Sentinel-2 satellite imagery with frequent updates.  

- **[Copernicus Global Historic GLOF Database](https://essd.copernicus.org/articles/15/2983/2023/)**  
  Historic glacier lake outburst flood events global database with satellite image references.  

- **[Glacier Lake Outburst Flood (GLOF) Database V3.0 (Zenodo)](https://zenodo.org/records/7330345)**  
  Labeled dataset of glacier lakes and flood events for machine learning and research.  

## Research Papers and Model References
- **[Glacier Flood Detection using Deep Learning Through Satellite Images](https://www.ijert.org/glacier-flood-detection-using-deep-learning-through-satellite-images)**  
  A research paper detailing CNN model training for glacier flood prediction using satellite data.  

- **[Deep Learning Model for Glacial Lake Detection Using Multi-source Satellite Imagery](https://www.sciencedirect.com/science/article/pii/S2666017224000415)**  
  Study on combining satellite data and CNN models for precise flood mapping.  

- **[CNN-based Glacier Flood Detection Research (SSRN)](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4832583)**  
  Preprint paper on glacier flood detection mechanisms with CNN architectures.  

## Regional Monitoring and Risk Assessment
- **[Himalayan Glacial Lakes Flood Risk News & Studies](https://economictimes.com/news/new-updates/himalayan-glacial-lakes-across-ladakh-jammu-and-kashmir-himachal-pradesh-flagged-over-risk-of-destructive-flooding/articleshow/123655523.cms)**  
  Recent updates on glacier lake flood risks in Uttarakhand, HP, and J&K.  

- **[Satellite Insights on Expanding Glacial Lakes in Indian Himalayas (ISRO)](https://www.isro.gov.in/Satellite_Insights_Expanding_Glacial_Lakes_Indian_Himalayas.html)**  
  Insights on glacial lake changes in Uttarakhand and nearby regions using satellite data.  

## Live Satellite Data Feeds for Real-time Monitoring
- **[ESA Sentinel Near Real-Time Data](https://sentinel.esa.int/web/sentinel/home)**  
  Access to live updates of satellite data for ongoing monitoring.  

- **[NASA LANCE (Land, Atmosphere Near real-time Capability for EOS)](https://earthdata.nasa.gov/earth-observation-data/near-real-time)**  
  Near real-time satellite data streams from NASA for Earth monitoring including glaciers.
